Upload Tester

Send a payload to /api/upload. The server answers with the number of bytes it received.

per second

Streams the body at a fixed rate (chunked, no Content-Length) to hit request/body timeouts of proxies and servers. Browsers only allow streamed request bodies over HTTP/2 or HTTP/3, so put a TLS proxy in front when testing this.

Find maximum size

Uploads growing generated payloads (doubling, then bisecting) until the first one fails, and reports the largest size that went through.
